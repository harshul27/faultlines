# Pitch

The demo video, the pitch deck and the pitch text for Fault Lines.

| File | What it is |
|---|---|
| [`demo-video.mp4`](demo-video.mp4) | 1:44 demo film, 1080p, captured from the running app on a synthetic match. Original music, made for the film. |
| [`fault-lines-pitch.pdf`](fault-lines-pitch.pdf) | The pitch deck as 13 static slides (1920×1080). |
| [`deck/deck.html`](deck/deck.html) | The same deck, animated, with speaker notes. Open it in a browser: arrow keys to present, **P** presenter view, **O** overview, **F** fullscreen. Needs an internet connection for its fonts. |
| [`deck/SCRIPT.md`](deck/SCRIPT.md) | The deck's storyline, one row per slide. |
| [`pitch.md`](pitch.md) | The pitch as text, with a short version for a form field. |
| [`share-copy.txt`](share-copy.txt) | A short post to share the project. |

The deck is built on [deck-kit](https://github.com/kiselas/every-slide-is-code) (MIT). The network on slides 1, 3, 4 and 13
is illustrative; its fragility numbers are computed in the deck with the same formula as `src/network.py`. Proof numbers
come from [`reports/validation.md`](../reports/validation.md) and [`reports/evaluation.md`](../reports/evaluation.md).
